One challenge in this project was coordinating multiple API providers while handling failures, request pacing, and usage costs; I addressed it with provider fallback, cost tracking, and asynchronous article processing, then verified the workflow with mocked unit tests. 
I learned how to connect a news API to LLM summarization and sentiment analysis, and how tests can check the workflow without making live, billable requests. If I continued improving the project, I would add persistent daily budget tracking and more precise per-provider rate limits. I had issues with news_api key but then I changed and it worked.
